Phím tắt hệ thống (Keyboard Shortcuts)

Phím tắt (Shortcut) Thao tác & Mô tả (Action & Description)
Alt + Space
Ẩn / Hiện nhanh cửa sổ từ bất cứ đâu (Global Summon)
Thu nhỏ hoặc gọi cửa sổ ứng dụng lên màn hình chính. Có thể tùy chỉnh trong Settings.
Ctrl + ,  /  ⌘ + ,
Mở Cài đặt launcher (Settings)
Cấu hình kết nối server, bảo mật Agent, phím tắt và danh mục thư mục được phép.
F1
Mở Trợ giúp & Phím tắt này (Help & Shortcuts)
Hiển thị nhanh trang tài liệu tham khảo và bảng phím tắt này bất cứ lúc nào.
F11  /  Ctrl + Shift + F
Chế độ Focus tập trung toàn màn hình (Focus Mode)
Ẩn các thanh bên (Sidebar và Canvas) để tập trung hội thoại và đặt trọng tâm vào composer.
Alt + S
Bật / Tắt Sidebar danh sách hội thoại
Đóng/mở ngăn bên trái chứa danh sách hội thoại, server switcher và các cài đặt nhanh.
Alt + C
Bật / Tắt Right Canvas (Intel Suite)
Đóng/mở ngăn giao diện mở rộng bên phải phục vụ phân tích dữ liệu và trình bày nội dung.
Ctrl + +  /  Ctrl + -  /  Ctrl + 0
Phóng to, thu nhỏ, đặt lại kích thước giao diện (Zoom Control)
Điều chỉnh tỷ lệ zoom giao diện trong khoảng [0.7x – 2.0x] và tự động lưu cấu hình.
Ctrl + Shift + R  /  F5
Làm mới sạch ứng dụng (Hard Refresh)
Đặt lại toàn bộ bộ nhớ tạm, CSRF token, kết nối WebSocket và tải lại iframe Canvas.

Tính năng Agent điều khiển máy (Outbound Gateway Hub)

Remote Files files

Cho phép Agent đọc, ghi, sửa và patch tệp trong các thư mục được cấp phép (mặc định ~/Workspace). Ngăn chặn truy cập ngoài phạm vi cho phép.

Terminal Execution code_execution

Cho phép Agent chạy các lệnh shell qua phiên PTY cục bộ được cô lập, hỗ trợ lệnh chạy dài và truyền kết quả trực tiếp về máy chủ.

Host Browser browser

Cho phép Agent tự động hóa Google Chrome hoặc Microsoft Edge qua cổng CDP (Chrome DevTools Protocol) 9222 để điều hướng và kiểm thử web.

Computer Use computer_use

Cho phép Agent chụp ảnh màn hình desktop và mô phỏng chuột, bàn phím trực tiếp trên hệ điều hành để tương tác với các ứng dụng máy tính.

Cấu hình an toàn & Lưu ý môi trường

Phím tắt toàn cục trên Linux Wayland (Wayland Note)
Phím tắt toàn cục (Global Hotkey như Alt+Space) hoạt động trực tiếp trên X11, Windows và macOS. Trên Wayland compositor (với chính sách bảo mật hạn chế global keyboard grab của ứng dụng bên thứ 3), vui lòng sử dụng biểu tượng khay hệ thống (System Tray) để bật/tắt cửa sổ, hoặc cấu hình phím tắt trong Window Manager gọi lệnh aqvn-workspace.
Thư mục an toàn (Allowed Paths & Sandbox)
Agent chỉ được phép thao tác tệp trong các đường dẫn đã khai báo rõ ràng trong mục Allowed Paths tại Cài đặt. Mọi truy cập vào các thư mục nhạy cảm bên ngoài (như /etc, ~/.ssh, v.v.) đều bị từ chối triệt để ở tầng Rust backend.
Nguyên tắc đặc quyền tối thiểu (Least Privilege Scopes)
Trong mục Cài đặt (Settings), bạn có thể bật/tắt riêng lẻ từng quyền bảo mật của Outbound Gateway Hub hoặc tắt hoàn toàn công tắc tổng khi không cần Agent tương tác với máy cục bộ.
