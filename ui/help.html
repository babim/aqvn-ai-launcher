Bridge & Architecture Features

Accelerated Loopback Proxy

Binds a loopback proxy server to route WebUI requests, maintain session persistence, and handle cross-origin bridging.

Outbound Gateway Hub (_a0_connector)

Provides persistent WebSocket connection for file streaming, sandboxed process execution, browser automation, and desktop computer use.

Sandboxed RFC & SSH Bridges

Local authenticated RPC and SSH tunnels with workspace path containment and configurable listen ports.
